# ai-chat-assistant

Next.js AI chat assistant with speech input, file upload, Markdown rendering, and tool/function workflows.

## Features

- AI chat interface.
- Speech input support.
- File upload workflow.
- Markdown response rendering.
- Tool/function workflow foundation.

## Tech Stack

- Next.js
- TypeScript
- React
- Markdown tooling

## Getting Started

```bash
npm install
npm run dev
```

## Status

Prototype project for AI assistant workflows.
